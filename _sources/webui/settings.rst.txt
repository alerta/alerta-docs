.. _settings:

User Preferences
================

The user preferences page allows each user to customize their web console
experience. Access it by clicking your user avatar in the top-right corner
and selecting *Settings*.

Application Settings
--------------------

- **Dark theme** -- toggle between light and dark mode for the console
- **Notification sounds** -- enable or disable audio alerts when new alerts
  arrive or alert severity changes

Language Settings
-----------------

Select the display language for the web console. Available languages include:

- English
- French
- German

The language setting affects UI labels and messages but not alert data.

Date and Time Settings
----------------------

Configure how dates and times are displayed throughout the console:

- **Short time format** -- used for compact timestamp displays (e.g. in the
  alert list)
- **Medium date format** -- used for standard date displays
- **Long date format** -- used for full date/time displays (e.g. in the
  alert detail view)
- **Time display mode** -- choose between local time and UTC

Alert Summary Settings
----------------------

- **Rows per page** -- set the number of alerts displayed per page in the
  alert list (e.g. 10, 20, 50)
- **Refresh interval** -- how often the alert list auto-refreshes (in
  seconds)
- **Default shelve timeout** -- the default duration when shelving an alert
  from the web console

.. note:: User preferences are stored in the browser's local storage and
          apply only to the current browser. They do not sync across devices.
